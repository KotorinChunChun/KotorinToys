# KotorinToys 利用ガイド

KotorinToysは、収録したWindows向け便利ツールの導入、起動、状態確認、自動起動予約、使い方へのアクセスをまとめて扱う管理アプリケーションです。

一覧でツールを選び、「起動 / 画面を開く」で停止中のツールを起動します。実行中の場合は既存画面を表示します。「正常停止」でツールの終了処理を要求します。「状態を更新」で再確認し、「使い方」で各ツールのREADMEを開きます。状態は4秒ごとにも更新します。

起動処理中、実行中、停止処理中、停止中、確認できないを区別します。SSCaptureの撮影・録画中は、ツール側で操作を完了またはキャンセルしてから本体の「正常停止」を再実行してください。応答しないプロセスを本体から強制終了する機能はありません。

本体を閉じてもツールと通知領域アイコンは動作を続けます。今回の開発版は起動・停止・状態確認の連携を提供します。インストール管理と自動起動予約は未実装です。
