# READMEと文書の利用者・開発者分離

2026-10-25の依頼。対象はKotorinToys本体のREADMEと現行説明書。製品版は変更せず、catalog/host.jsonの0.1.11へ属する文書整備として記録する。開始時の親HEADは3f7af7f、作業場所はfeature/full-refactoring。別のv0.1.12作業ツリーや、子の未コミット変更・先行HEADを混ぜない。

## 依頼と方針

- READMEを利用者向けの説明書にする。開発・進捗は専用資料へ分離する。
- 文書全体の入口、読み手、現行操作との一致を見直す。
- ソース・定義・導入済みアプリ・設定・履歴を変更しない。公開・実導入は別工程とする。
- 管理対象アプリの個別説明は各独立リポジトリを正本とし、本体から案内する。子READMEの既存差分やGitリンクをまとめて変更しない。
