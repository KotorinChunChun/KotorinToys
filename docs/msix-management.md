# HttpSelectorを導入・更新する

HttpSelectorはMSIX形式で配布します。KotorinToysの一覧から導入・更新・削除し、署名やアプリの識別を確認します。

## 操作

1. 「状態を更新」を押し、HttpSelectorを選びます。
2. 未導入なら「インストール」、新しい公開版がある場合は「アップデート」を押します。対象版と公開日は確認画面やツールチップで確認できます。
3. 対象を確認して実行します。停止できない場合や署名を確認できない場合は中止し、理由を表示します。
4. 削除する場合は「アンインストール」を使います。

まとめて操作する場合は「一括インストール」を開きます。

初回に署名の信頼を確認するよう求められたら、[HttpSelectorの導入説明](https://github.com/KotorinChunChun/HttpSelector/blob/main/docs/INSTALL_MSIX.md)を読み、配布元と証明書を確認してください。本体は証明書を自動登録しません。

HTTP／HTTPSの関連付け候補が登録された後、既定アプリの選択はWindowsの設定で行います。インストールしただけで既定のブラウザーを変更する操作とは別です。

## 設定と履歴

KotorinToys経由の更新・削除ではアプリのデータを退避し、同じユーザーで再導入するときに復元します。退避・照合できない場合や、既存データと競合する場合は「要確認」で止まります。

Windowsの設定から直接削除した場合や、保持領域まで手動で削除した場合は本体で事前退避できません。データを保持する操作は本体から行ってください。「リセット」は設定を消す可能性があるため選ばないでください。

## エラーが出たら

| 表示の例 | 確認すること |
| --- | --- |
| 証明書の信頼（0x800B0109） | 配布元の導入説明と証明書 |
| アプリ使用中（0x80073D02） | アプリ側の作業を終えて正常終了 |
| 依存・競合（0x80073CF3） | 画面の詳細とWindows側の登録状況 |
| アクセス権・ポリシー（0x80070005） | 画面の詳細、導入先やPCの利用制限 |

原因を確認できない場合は、エラー表示を控えて問い合わせてください。強制終了・自動削除・PCの自動再起動で解決する処理は行いません。

[使い方に戻る](USERS_GUIDE.md)。署名・識別・退避の詳しい条件は[開発者向け仕様](development/msix-management.md)へ分けています。
