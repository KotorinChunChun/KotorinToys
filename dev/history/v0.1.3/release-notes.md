# KotorinToys 0.1.3 開発版

Windows 11 x64向けの未署名の開発版（prerelease）です。.NET Desktop Runtimeを同梱しています。

- インストール確認・進行中・全件完了のメッセージを簡潔にしました。失敗・要確認時の理由は引き続き表示します。
- メイン画面下部の重複した状態説明を整理しました。
- 本体をアップデートできない場合に、導入先・実行先・版などの具体的な原因と対処を表示します。
- ツール一覧に自動起動の方式と有効性を表示します。本体経由、OSのタスク／スタートアップ、登録なし、要確認などを区別します。
- ShortcutKeyCounterのポータブル公開版の版・公開日を表示します。本体用インストーラーとは区別します。

## ダウンロードと更新

`KotorinToys-0.1.3-setup.exe` を実行してください。既存導入先へ更新し、設定・履歴・自動起動予約を保持します。

旧版の「本体アップデート」から取得する場合は「開発版（prerelease）も更新対象にする」を有効にしてください。同意とSHA-256照合後に本体だけを終了・更新・再起動します。PCの自動再起動や子ツールの強制終了はしません。

`KotorinToys-SHA256SUMS.txt` はEXEのSHA-256、`KotorinToys-packages.json` は本体の更新機能が照合する配布台帳です。未署名のため、Windowsが発行元を確認できない旨を表示することがあります。

## 確認済みの範囲

全体自動テスト753件、本体の保持付き更新、PC再起動後の本体0.1.3・LiveTextMarker・SmartPaste・SSCaptureの自動起動と準備完了、設定・保存ファイルの保持を確認しました。実デスクトップの見た目や各ツールの撮影・OCR等、全機能の受入完了を保証する版ではありません。

子ツールのインストーラー・FFmpeg等はこのReleaseへ同梱しません。各ツールの公開先と本体の導入機能から確認してください。
