# KotorinToys本体を更新する

アプリ一覧の「アップデート」は選択したアプリの更新です。KotorinToys自身の更新には「本体アップデート」を使います。

## 更新する

1. 「本体アップデート」を開き、現在の版と公開版を確認します。
2. 必要な場合だけ「開発版（prerelease）も更新対象にする」を選びます。
3. 更新対象と注意事項を確認し、本体の終了・更新・再起動への同意にチェックします。
4. 「ダウンロードして本体を更新」を押します。
5. 本体が再起動したら、この画面で前回の更新結果を確認します。

設定・履歴・自動起動の設定を保持し、本体だけを更新・再起動します。子アプリやPCは自動で再起動しません。

## 更新ボタンを押せないとき

| 原因 | 対処 |
| --- | --- |
| 新しい公開版がない | 現在の版を継続して使えます |
| 公開情報を確認できない | 通信状態を確認し、画面の案内に従って再確認します |
| 開発版を対象にしていない | 開発版を使いたい場合だけチェックして再確認します |
| インストール済みの本体ではない | 表示された正式な導入先から本体を起動します |
| 実行先・登録・版が一致しない | 画面の理由を確認し、必要ならReleasesのsetupで更新します |
| 同意が未確認 | 対象と注意事項を確認して同意にチェックします |

詳しい原因は更新画面に表示します。設定や履歴を削除して解決しようとしないでください。

## 取り消しと失敗

取得・準備中は取り消せます。更新開始後は強制的に中断しません。失敗・要確認・再起動待ちの場合は、画面の結果と理由を確認してください。

自動で旧版へ戻す機能はありません。必要なら[GitHub Releases](https://github.com/KotorinChunChun/KotorinToys/releases)からsetupを取得して再導入します。自己更新機能がない旧版もsetupで更新できます。

通常の結果記録は`%LOCALAPPDATA%\KotorinToys\updates`へ保存します。作業中の記録を削除せず、問い合わせ前にユーザー名や導入先などの情報が含まれていないか確認してください。

[使い方に戻る](USERS_GUIDE.md)。開発・配布条件は[開発者向けの自己更新仕様](development/self-update.md)に分けています。
