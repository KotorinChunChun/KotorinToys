# KotorinToys 利用ガイド

KotorinToysは、収録したWindows向け便利ツールの導入、起動、状態確認、自動起動予約、使い方へのアクセスをまとめて扱う管理アプリケーションです。

一覧でツールを選び、「起動 / 画面を開く」で停止中のツールを起動します。実行中の場合は既存画面を表示します。「正常停止」でツールの終了処理を要求します。「状態を更新」で再確認し、「使い方」で各ツールのREADMEを開きます。状態は4秒ごとにも更新します。

データ行のダブルクリックでも「起動 / 画面を開く」を実行します。起動済みの画面は前面へ表示し、最小化されている場合は復元します。

起動処理中、実行中、停止処理中、停止中、確認できないを区別します。SSCaptureの撮影・録画中は、ツール側で操作を完了またはキャンセルしてから本体の「正常停止」を再実行してください。応答しないプロセスを本体から強制終了する機能はありません。

本体を閉じてもツールと通知領域アイコンは動作を続けます。「本体設定・自動起動」でサインイン時の起動方式を設定できます。

## 導入・削除の完了表示

「導入・削除」で対象をチェックし、インストール／更新またはアンインストールします。未署名の開発版であることを確認してから進めてください。設定・履歴は保持します。

処理が終了すると、上部に成功・失敗・要確認・再起動待ち・未実行の件数、表に各製品の結果と理由を表示します。「詳細ログを表示」で途中経過を確認できます。全件成功と一部失敗は区別し、完了後は「閉じる」で本体へ戻れます。再起動待ちの場合も自動再起動はしません。

## SSCaptureのFFmpeg導入

SSCaptureを正式導入し、本体の「正常停止」で停止した後、「導入・削除」の「FFmpegを導入 / 修復」を押します。固定9.0.2のFFmpeg／FFprobeを[FFmpeg公式が紹介する配布元](https://ffmpeg.org/download.html)の[Gyan GPLv3ビルド](https://www.gyan.dev/ffmpeg/builds/)から直接取得します（約110 MB）。再起動して録画を確認してください。

容量と固定SHA-256を照合し、実行ファイル横のtoolsへ録画用の2ファイルとライセンス・READMEを配置します。これは署名による発行元検証や実録画の確認ではありません。既存ファイルはバックアップ付きで置き換え、失敗時は元へ戻します。復旧未完了の場合はエラーに示したバックアップを削除しないでください。設定・履歴・WindowsのPATHは変更せず、公開済みインストーラーへの同梱もしません。
