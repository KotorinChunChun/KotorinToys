# KotorinToys v0.1.14

Windows 11 x64向けの未署名プレリリースです。

- 未導入アプリの「アップデート」ボタンに、先に「インストール」を押す案内を表示します。
- SSCapture 0.1.6の公開情報を反映しました。SSCapture 0.1.1の日本語の登録名や古い製品定義が残っている場合でも、製品と配布物を照合できれば更新できます。
- SSCaptureの旧版から新しいインストーラーへの実更新を専用フォルダーで確認し、設定・履歴・撮影結果・FFmpegの保持を確認しました。別PCでの更新は未確認です。

既存の設定・履歴を保持してインストールできます。本体の「本体アップデート」から更新する場合は、開発版を更新対象に含めてください。実行中のアプリが正常終了を拒否したときは更新を中止します。SHA256SUMSで配布ファイルの一致を確認できます。
