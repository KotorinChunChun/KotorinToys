# ポータブル版の公開表示

開発版ではShortcutKeyCounterの公開ZIPを検出し、「公開版・公開日」に`0.1.5（2026/10/17 公開）（ポータブル版）`のように表示する。公開日はGitHub Releasesの公開日時を日本時間へ変換する。

公開の検出と本体からの導入対応は別に判定する。ShortcutKeyCounterの`distributionStatus: unpublished`は本体用Innoインストーラーが未公開という意味であり、ポータブルZIPの未公開を意味しない。ポータブル版は公開情報専用の型で扱い、インストーラーの配布台帳へ入れない。

インストール・アップデートボタンは無効のままとし、「本体からの導入・更新は未対応」と案内する。「GitHubを開く」からReleaseへ進み、ZIPを展開して単独で利用する。ZIP公開の確認だけでEXEをダウンロード・展開・実行したり、既存DB・自動起動を変更したりしない。

## 照合条件

- 固定所有者・製品のGitHub Releases APIで、下書きを除外し数値版の最新候補を選ぶ。公開済み開発版は開発版として表示する。
- 固定版の`ShortcutKeyCounter-vX.Y.Z-win-x64.zip`と`SHA256SUMS.txt`が一意・uploadedであることと、所有者・リポジトリ・tag・ファイル名に一致するURLを検査する。
- ZIPは正の容量で512 MiB以下、ハッシュ台帳は32 KiB以下。表示時にZIP本体は取得しない。
- ハッシュ台帳の対象ZIP行が一意でSHA-256形式であることを確認し、GitHubがasset digestを提供する場合は一致を要求する。
- 通信失敗、GitHub APIの回数制限、欠落・重複・不一致を公開確認済みにしない。制限解除後に「状態を更新」で再確認する。

## 検証用コマンド

テスト実行ファイルの`--portable-release-check`は実際の公開APIとハッシュ台帳を取得する。API回数制限時は第2引数にCLIで取得した公開API応答JSONを渡すと、API応答だけを再利用し、ハッシュ台帳は匿名で実取得する。この結果を匿名APIでの成功と混同しない。認証情報は本体・設定・ログへ保存しない。

`--portable-release-panel [API応答JSON]`は設定・自動起動の管理部から分離した確認用Dashboardを画面右側へ表示する。インストール済み本体の実装が自動的に置き換わるものではない。配布済みv0.1.2にこの変更は含まれず、更新版の本体への入替が必要。
