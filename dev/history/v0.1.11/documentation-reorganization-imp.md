# READMEと文書の利用者・開発者分離

2026-10-25の依頼。対象はKotorinToys本体のREADMEと現行説明書。製品版は変更せず、catalog/host.jsonの0.1.11へ属する文書整備として記録する。開始時の親HEADは3f7af7f、作業場所はfeature/full-refactoring。別のv0.1.12作業ツリーや、子の未コミット変更・先行HEADを混ぜない。

## 依頼と方針

- READMEを利用者向けの説明書にする。開発・進捗は専用資料へ分離する。
- 文書全体の入口、読み手、現行操作との一致を見直す。
- ソース・定義・導入済みアプリ・設定・履歴を変更しない。公開・実導入は別工程とする。
- 管理対象アプリの個別説明は各独立リポジトリを正本とし、本体から案内する。子READMEの既存差分やGitリンクをまとめて変更しない。

## フェーズ

- [x] P1：READMEを利用者の導入・日常操作へ整理し、説明書目次と編集方針を追加。5文書のローカル参照28件・見出し・差分を確認してコミットする。
- [ ] P2：開発者ガイドを分野別の入口へ整理し、自己更新・MSIX等の混在資料も分離する。古いFAQと版固有の案内を訂正し、文書検査後にコミットする。
- [ ] P3：現行文書全体と参照・テンプレートを再点検し、検査結果と未実施範囲を記録してコミットする。

## 確認した問題

- READMEに古い件数、v0.1.8の固定ダウンロード、ソース取得、ビルド、個別ツールの追加・公開結果が混在していた。
- FAQが初期3ツール時点のままで、導入管理・自動起動を未実装と説明していた。
- 開発者ガイドが実装詳細・各ツールの検証・配布・過去の版を一ページへ集め、同じ説明を繰り返していた。
- 自己更新・MSIX資料に利用手順と開発検証が混在し、旧ボタン名・廃止済み公開Ver列の説明も残っていた。
- ソースの旧self-testは9件固定で現行catalog14件と一致しない。文書整備では製品コードを変更せず、現行の推奨検証入口として案内しない。
