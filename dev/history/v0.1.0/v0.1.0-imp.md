# v0.1.0 準備計画・実装報告

## 2026年10月11日: 3ツールの管理実装

格納済み3ツールの確認後、本体をC# / .NET 10 / Windows Formsで作成した。catalog/tools.jsonに実行先とREADMEを登録し、一覧、起動、既存画面表示、正常停止、4秒ごとの状態確認、使い方表示を実装した。本体を閉じてもツールは動作を継続する。

各子リポジトリにCurrentUserOnlyの名前付きパイプ窓口を追加した。正常停止要求は各ツールの既存終了処理へ渡す。実行パス、セッション、応答PIDを確認し、応答が得られないプロセスを停止中として扱わない。撮影・録画中のSSCaptureは終了を保留し、本体に停止処理中を表示する。

本PCに.NET 8 Desktop Runtimeがなかったため、LiveTextMarkerとSmartPasteをランタイム同梱でビルドした。既存設定の保存方式、通知領域アイコン、各リポジトリの独立性を維持した。旧プロセスの初回切替ではユーザーの明示許可により強制終了した。以後の管理停止は正常終了処理を使う。

検証結果: 本体と3ツールのビルド成功。SSCapture 325件、SmartPaste 150件、LiveTextMarker 47件の既存テスト成功。実プロセスの統合テストで3ツールの起動、既存PID維持、画面表示要求、正常停止、再起動を検証。本体のウィンドウ起動を確認した。画面のピクセル比較、ボタンの実クリック、撮影・録画中の終了保留の実操作、各ツール固有の全機能は今回未検証。

本体と3ツールの開発出力はローカルビルド成果物で、公開・インストーラー作成は行っていない。インストール管理と自動起動予約は今後の実装対象。
