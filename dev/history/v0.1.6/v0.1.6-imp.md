# KotorinToys 0.1.6 実装計画・報告

対応要求: [要求](v0.1.6-req.md)。2026-10-19。ブランチ: `feature/full-refactoring`。

## 0. 事前確認と原因

旧導入経路はInno EXE専用でMSIXを明示拒否していた。[0.1.4でのP1/P2記録](../v0.1.4/v0.1.4-imp.md)のとおり、MSIX公開情報・固定署名・BlockMap照合・Windows PackageManager・データ保持を実装した。

EveryDB完了ブランチ`feature/everydb-common-installer`は0.1.5公開済みで、旧作業checkoutには未統合だった。共通の親21571beから分岐した4コミットだけを現在の作業ブランチへ統合する。版の競合を0.1.6へ解消し、テストはEveryDB側の7製品・0.1.1の契約を採用する。mainや公開先は変更しない。

## 1. フェーズ・コミット単位

- [x] P1: EveryDB対応を統合、版の競合解消、本体・Maintenanceビルド、全体回帰。
- [x] P2: MSIXをメイン・詳細操作へ接続、版・公開日・ボタン状態・未知Identity拒否を検証。
- [ ] P3: 利用ガイド、実公開MSIX取得・署名と全内容・OS登録の読取照合、最終回帰・記録。

## 2. 要件別方針

- R1: `ToolInstallationRunner`のMSIX拒否を固定Identity限定の許可へ変更し、Innoへ混入させない。`ToolVersionView`の更新が必要を導入済み扱いにし、MSIXはunins000.exeなしで正式登録を削除対象にする。台帳不一致や未確認公開情報では実行しない。
- R2: 完了ブランチをfeatureへ統合し、EveryDBの固定製品登録・公開台帳・配布スクリプト・文書を維持する。MSIXはHTTP応答MIME依存のAppInstallerではなく、検証済みローカルMSIXを現在ユーザーに展開する。

## 3. 実装・検証結果

- P1: 本体・テスト・Maintenanceビルド成功、警告・エラー0。全回帰808件成功。EveryDB 0.1.1の固定配布先・版・ハッシュ・7製品台帳の回帰を維持した。ログは`logs/integration/tests.log`（Git対象外）。
- MSIX先行実装: P1 `c135494`、P2 `41ac2be`。署名・payload・データ保持の限定72件と、公開0.0.3.3の実署名・全ブロック・現在ユーザー登録の読取照合が成功。
- P2: 本体・テストビルド成功（警告・エラー0）、MSIX限定82件、全回帰823件成功。実WinFormsの各セル・ボタン状態と単体操作への呼出しを測定。未導入・旧版・同版・登録不能・公開確認失敗を確認し、署名確認やIdentityを省く経路は拒否した。目視UI・実OS展開の受入ではない。
- 統合コミット: `0e12e7a`（EveryDB側の完了4コミットを保持）。

## 4. 申し送り

実OSのMSIX導入・更新・削除／再導入、別PCの信頼未登録環境、Windows既定アプリの変更後は未受入。自動テストでのOS注入と実OSへの展開を混同しない。公開済み本体やこのPCの稼働中本体の版は変更しない。
