# アプリケーションのリリース手順

本ドキュメントでは、Rustで開発されたWindows用アプリケーションの実行ファイル（ZIP版）およびインストーラをビルドし、リリースパッケージを作成するための一般的な手順を説明します。

> **Note（配置とGit方針）**
> リリーススクリプトは `dev/scripts/release-<アプリ名>.ps1` に置きます（原本は `default` プロジェクトの `dev/templates/release-Sample.ps1`）。
> 成果物の出力先 `release/` は **Git対象外**です。配布は `release/Publish/` に置いたファイルをGitHub Releasesへアップロードして行います。

## 1. 前提条件

リリースを作成するには、以下のツールがインストールされている必要があります。

- **Rust / Cargo**: アプリケーション本体のコンパイル用
- **インストーラ作成ツール (NSIS, Inno Setup, WiXなど)**: インストーラの生成用（使用している場合）
- **PowerShell**: リリース自動化スクリプトの実行用
- **GitHub CLI (`gh`)**: （任意）GitHubへのリリースおよびアセットの自動アップロード用。未インストールや未ログインの場合はローカルでのファイル出力のみが行われます。

## 2. バージョンの更新

リリースを作成する前に、プロジェクトのバージョン番号を新しいものに更新します。
以下のファイルの `version` の値を書き換えてください。

- `Cargo.toml`
- （プロジェクト固有のUIフレームワーク設定ファイルなどがある場合は適宜追加）

> **Note**
> 自動リリーススクリプト (`dev/scripts/release-<アプリ名>.ps1`) は `Cargo.toml` からバージョン情報を読み取るため、このファイルの更新は必須です。

## 3. リリースの作成（自動化スクリプト）

`dev/scripts/` に配置した自動化スクリプト `release-<アプリ名>.ps1` を実行することで、ビルドからパッケージ化、GitHubへのリリースまでを一括で行うことができます。このスクリプトは `default` プロジェクトの `dev/templates/release-Sample.ps1` を複製し、先頭の設定変数（アプリ名など）を書き換えて作成します。

```powershell
.\dev\scripts\release-<アプリ名>.ps1
```

### スクリプトの実行プロセス

スクリプトを実行すると、以下の処理が自動で進行します。

1. **バージョンの確認**:
   `Cargo.toml` からバージョンを読み取り、実行してよいか確認のプロンプトが表示されます。`y` を入力して続行します。
2. **ビルドの実行**:
   Rustプロジェクトがリリースモードでコンパイルされます。（例: `cargo build --release`）
3. **ファイルの収集とZIP化（ポータブル版）**:
   実行ファイル (`<アプリ名>.exe`) や依存DLL、`README.md` などの必要なリソースが収集され、ZIP 形式に圧縮されます。
   - 一時出力先: `release/<アプリ名>_v{バージョン}.zip`
4. **インストーラの直接出力・配置**:
   Inno Setup 等のコンパイラオプション（例: `/O"release" /F"<アプリ名>_v{バージョン}_Setup"`）を使用し、インストーラが指定のディレクトリに直接生成・配置されます。
   - 一時出力先: `release/<アプリ名>_v{バージョン}_Setup.exe`
5. **GitHub Release の作成・更新（任意）**:
   `gh` コマンドが利用可能な場合、指定されたバージョンのタグでリリースが作成（または更新）され、ZIPとインストーラが自動的にアップロードされます。既存のリリースが存在する場合は、上書き確認プロンプトが表示されます。
6. **公開用アーカイブへの移動**:
   生成されたZIPファイルとインストーラは、公開用アーカイブとして `release/Publish` フォルダに移動されます（既存のファイルは上書きされます）。
   - 最終保存先:
     - `release/Publish/<アプリ名>_v{バージョン}.zip`
     - `release/Publish/<アプリ名>_v{バージョン}_Setup.exe`

## 4. 手動でビルドする場合

自動化スクリプトを使用せずに、手動でビルドおよびパッケージ化を行う場合は、以下のコマンドを実行します。

### 実行ファイルのビルド

```powershell
cargo build --release
```

実行が完了すると、以下の場所に実行ファイルが生成されます。

- **実行ファイル**: `target/release/<実行ファイル名>.exe`

### インストーラの作成

採用しているインストーラ生成ツール（Inno Setupなど）の手順に従い、生成された実行ファイルをパッケージ化してください。
（例: Inno Setup で `release` ディレクトリに直接出力する場合）

```powershell
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" /O"release" /F"<アプリ名>_v{バージョン}_Setup" installer.iss
```

- **インストーラ**: `release/<アプリ名>_v{バージョン}_Setup.exe`

### 成果物の移動・整理

生成された ZIP ファイルおよび Setup.exe を `release/Publish/` へ移動します。
