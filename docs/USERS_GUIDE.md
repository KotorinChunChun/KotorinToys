# KotorinToys 利用ガイド

KotorinToysは、収録したWindows向け便利ツールの導入、起動、状態確認、自動起動予約、使い方へのアクセスをまとめて扱う管理アプリケーションです。

本書はv0.1.2に対応します。導入操作整理・公開日表示・追加3ツールの本体対応配布を含みます。旧v0.1.1の公開資産は差し替えません。本体の「本体アップデート」で開発版も対象にするか、新しいsetupで更新してください。

2026年10月16日追加：この機能を含む本体への初回更新後は、GitHubのmain/config/tools.jsonの変更だけで一覧を差し替えます。起動時と「状態を更新」で取得し、追加・非表示・順序・一言解説を反映します。通信できない場合は前回の正常な一覧を維持します。一覧から削除しても停止・アンインストール・自動起動解除は行いません。[運用手順と制約](online-tool-catalog.md)を確認してください。

## 一覧の版・解説・状態

一覧にツールの一言解説、導入済み版、公開版と公開日、更新の要否を表示します。公開日はGitHub Releasesのpublished_atを日本時間の日付にし、バージョンの右に「0.1.5（2026/10/14 公開）」のように表示します。取得できない日付は「公開日不明」とし、確認日時を公開日の代わりには使いません。導入済み版は正式登録された実行ファイルから取得し、開発フォルダーだけの配置は「未導入」と区別します。

同梱初期一覧は9件で、取得したconfigによって変わります。LiveTextMarker／SmartPaste／SSCaptureに加え、CapchunWindow（旧CapchunScreen）／ChulipVideo C#版／ChunapToolの計6件が本体対応インストーラーを利用できます。開発版ではShortcutKeyCounterの[ポータブルZIPの公開版・公開日表示](portable-release-publication.md)に対応します。本体対応インストーラーは未公開のため、EveryDBの単体配布、HttpSelectorの署名付きMSIXとともに、本体のInno形式の導入・削除とは別経路です。未対応のボタンは無効になり、理由を案内します。CapchunWindowとChulipVideoのFFmpegは各アプリで指定します（本体のFFmpeg導入はSSCapture専用）。ひとこと解説はconfigのsummaryで変更できます。

起動時と「状態を更新」でGitHub Releasesと製品別配布台帳を照合します。独立した「公開版を確認」ボタンはありません。公開済み開発版も対象にし、開発版であることを併記します。通信失敗・API制限・台帳欠落では「公開版を確認できません」とし、同梱台帳の版を表示しても「最新です」とは判定しません。

メイン一覧で対象を選び、「インストール」「アップデート」「アンインストール」を操作します。インストールは未導入かつ対応する公開配布物を照合済みの場合だけ有効です。アップデートは正式導入済みで、照合済みの公開版が導入版より新しい場合だけ有効です。同版・未導入・未照合では無効になり、再確認には「状態を更新」を使います。アンインストールは正式導入と削除プログラムを確認できる場合だけ有効です。

インストール・アップデート時は公開情報と導入状態を再確認し、対象製品・導入済み版→取得対象版・公開日を確認した後、その1製品の進捗と結果を表示します。別の製品をチェックし直す必要はありません。GitHub Releasesが標準で、通常操作に取得元の選択は不要です。削除ではGitHubの照合を要求しません。既存の導入先と設定・履歴を保持し、正常停止の拒否時は中止します。実行中だった対象は更新後に起動状態へ復帰し、元が停止中なら起動しません。公開版より新しい導入済み版を古い版へ戻すことはありません。

メイン画面はツール一覧と2行の操作ボタンだけを表示します。状態・版・公開日は表で確認してください。操作できない原因や取得失敗は表の「詳細」、公開版の詳しい情報は公開版セルのツールチップに表示します。操作時のエラーは通知でも案内します。

「自動起動」列では、本体経由・OSのタスク／スタートアップ・なし・無効・確認不能を区別します。重複する経路は併記し、セルのツールチップで理由を確認できます。起動時と「状態を更新」、本体設定画面を閉じた後に読み直します。設定そのものは変更しません。[判定範囲と表示の意味](startup-settings.md#一覧の自動起動列)を参照してください。

操作ボタンは「選択中アプリ」と「本体全体」の別行です。選択行には「起動 / 設定を開く」「停止させる」「使い方を開く」「GitHubを開く」「インストール」「アップデート」「アンインストール」、本体行には「状態を更新」「本体設定・自動起動」「詳細設定（開発者向け）」「本体アップデート」を置きます。

「本体アップデート」は本体自身の現在版・公開版を確認し、新しい版をダウンロードして正常終了・保持付き更新・本体再起動を行います。正式版を既定とし、開発版は明示選択と同意が必要です。同版・旧版・未確認・開発実行では更新しません。取得・準備中は取消できます。子ツールの停止やOSの自動再起動は行いません。v0.1.1からの機能で、旧版からは最初に手動導入してください。[本体更新の詳細](self-update.md)を参照してください。

「GitHubを開く」は選択したアプリのリポジトリのトップページを既定ブラウザーへ渡します。configのrepositoryUrlで設定し、インストーラーの公開状態とは別に使用できます。同梱configでは既存4件とChunapToolの公開先を設定しています。公開先が未設定のアプリではボタンを無効にし、ツールチップに未設定と表示します。

一覧でツールを選び、「起動 / 設定を開く」で停止中のツールを起動します。実行中の場合は既存画面を表示します。「停止させる」で正常終了を要求し、停止中にはこのボタンを無効にします。「状態を更新」で状態と公開情報を再確認し、「使い方を開く」で各ツールのREADMEを開きます。実行状態は4秒ごとにも更新します。

データ行のダブルクリックでも「起動 / 設定を開く」を実行します。起動済みの画面は前面へ表示し、最小化されている場合は復元します。

起動処理中、実行中、停止処理中、停止中、確認できないを区別します。撮影・録画・書き出し等の処理中は、ツール側で操作を完了またはキャンセルしてから本体の「停止させる」を再実行してください。応答しないプロセスを本体から強制終了する機能はありません。

本体を閉じてもツールと通知領域アイコンは動作を続けます。「本体設定・自動起動」でサインイン時の起動方式を設定できます。

## 詳細設定と導入・削除の完了表示

複数製品の一括導入・削除、SSCaptureのFFmpeg導入、ローカル配布台帳の選択は「詳細設定（開発者向け）」にあります。「導入可能な全件を選択」で公開配布を確認できる製品を選び、「選択を一括インストール / 更新」または「選択を一括アンインストール」を使います。削除対象はチェックで個別指定できます。未対応製品を混ぜても各行に理由を表示し、他製品の処理を巻き込みません。未署名の開発版であることを確認してから進めてください。設定・履歴は保持します。

「ローカル配布台帳を選択」は信頼できるローカルビルドのpackages.jsonと隣接するsetup.exeを使う検証用機能です。通常利用には不要です。「取得元をGitHub Releasesに戻す」はローカル台帳の選択を解除するだけで、クリックしただけで取得や導入は行いません。ローカル台帳にGitHub公開日はないため「公開日不明」と表示します。

確認画面には対象・現在版・対象版・公開日と短い質問を表示します。全件成功したときは「すべてのインストールが完了しました。」と表示します。失敗・未実行・要確認・再起動待ちがあるときは件数と対象ごとの理由を残します。「詳細ログを表示」で途中経過や照合の詳細を確認できます。完了後は「閉じる」で本体へ戻れます。再起動待ちの場合も自動再起動はしません。

## SSCaptureのFFmpeg導入

SSCaptureを正式導入し、本体の「停止させる」で停止した後、「詳細設定（開発者向け）」の「FFmpegを導入 / 修復」を押します。固定9.0.2のFFmpeg／FFprobeを[FFmpeg公式が紹介する配布元](https://ffmpeg.org/download.html)の[Gyan GPLv3ビルド](https://www.gyan.dev/ffmpeg/builds/)から直接取得します（約110 MB）。SSCaptureを起動し直して録画を確認してください。

容量と固定SHA-256を照合し、実行ファイル横のtoolsへ録画用の2ファイルとライセンス・READMEを配置します。これは署名による発行元検証や実録画の確認ではありません。既存ファイルはバックアップ付きで置き換え、失敗時は元へ戻します。復旧未完了の場合はエラーに示したバックアップを削除しないでください。設定・履歴・WindowsのPATHは変更せず、公開済みインストーラーへの同梱もしません。

## HttpSelectorの導入

HttpSelectorは[署名付きMSIXの導入手順](../tools/HttpSelector/docs/INSTALL_MSIX.md)に従ってインストールしてください。HTTP/HTTPSの関連付け登録に必要なため、EXEのコピーだけで利用しません。MSIXの候補登録後、Windowsの「設定」→「アプリ」→「既定のアプリ」でHTTPとHTTPSにHttpSelectorを指定します。既定値を本体が強制変更することはありません。

本体は登録済みの署名付きMSIXを起動・表示・停止・状態確認します。未導入、旧版、登録確認不能のときはMSIX導入・更新の案内を表示し、開発EXEには切り替えません。Inno台帳によるインストール・更新とは別の導入経路です。自動起動には「KotorinToys経由」を選んでください。

危険性が疑われるURLやQuad9で確認できないURLは、割り込みオフやルール一致でも開く前に警告します。キャンセルが初期選択です。Quad9へ送るのはサブドメインを含むホスト名だけで、元URL・パス・クエリは送りません。詳しくは[HttpSelector利用ガイド](../tools/HttpSelector/docs/USERS_GUIDE.md)を参照してください。
