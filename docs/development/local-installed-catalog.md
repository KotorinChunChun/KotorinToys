# このPCに導入した未公開ツールの一覧

通常一覧は配信configを使う。このPCで手動導入した未公開製品は、設定ディレクトリの`local-tools.json`に配信config形式で明示する。`tool-catalog-cache.json`とは別のファイルであり、オンライン更新や取得失敗でも保持する。

通常の導入検出で製品ID・AppId・EXE製品名と導入先を確認できるものだけを表示する。未公開・MSIXなし・公開URLなし・`KotorinToys.<製品名>`・`<製品名>.exe`の定義に限る。配信一覧または履歴とIDやAppIdが重複する場合は配信側を優先し、ローカル定義では上書きしない。不正なローカルファイルは追加を行わず配信一覧を保持する。

ローカル登録は公開・配布の登録ではない。公開版のインストール・更新や自動起動を保証しない。製品ごとの導入・削除は、その製品が提供する手順とOSの登録を確認する。
