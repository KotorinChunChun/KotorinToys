# 本体設定と自動起動

サインインしたときに、使うアプリを自動で起動するための画面です。メイン画面の「本体設定・自動起動」から開きます。

通常は引数なしで起動すると利用者向け画面を開きます（KotorinToysは管理画面、SSCaptureは設定画面）。自動起動は画面を出さない共通の`--startup`を使います。KotorinToys自身の「サインイン時に管理画面も表示する」は既存の明示設定として残し、明示的な`--hidden`では常に非表示にします。

対応版のSSCaptureは「基本」の自動起動欄から直接タスクを設定できます。新規の既定はOFFで、本体と同じ予約・状態を使います。本体経由で設定済みなら単体から重ねて登録せず、この画面で変更します。ビルドやアプリの初回起動だけでは予約を作りません。

## アプリを自動で起動する

1. 設定したいアプリの行を選びます。
2. 「次回サインインの希望方式」を選びます。
3. 「選択ツールの方式を適用」を押します。
4. 「完了」と、実予約の「登録済み」を確認します。

1件ずつ保存します。別の行で選んだ方式は、未保存のまま残ります。設定しても、今動いているアプリが起動・停止することはありません。

| 方式 | 動き |
| --- | --- |
| 自動起動なし | 自動起動をやめる。今動いているアプリは停止しない |
| KotorinToys経由 | KotorinToysから起動する。通常はこちら |
| 直接タスク | Windowsから直接起動する。MSIX版では選べない |

## 下のボタン

| ボタン | 保存・実行する内容 |
| --- | --- |
| 本体設定を適用 | 上のチェック2項目を保存する。アプリの方式は保存しない |
| 選択ツールの方式を適用 | 選択中の1行の方式だけを保存する |
| 未完了操作を復旧 | 途中で中断した予約変更を元に戻す。必要なときだけ押せる |
| 状態を再取得 | 今の予約を確認する。編集中の選択は保存も破棄もしない |

上の「本体をサインイン時に開始する」はKotorinToys自身の設定です。「サインイン時に管理画面も表示する」をオフにすると、管理画面を出さずに開始します。

## グレーになって選べないとき

- 未導入：先にアプリをインストールしてください。ZIP版・開発版の配置だけでは、この画面から自動起動を設定できません。
- ファイルなし：導入したファイルが移動・削除されていないか確認し、必要なら再インストールしてください。
- 保存済み：設定を変更すると「適用」が押せます。
- 処理中：終わるまでお待ちください。
- 復旧が必要：先に「未完了操作を復旧」を押してください。

詳しい理由は表の「設定できない理由・案内」か、ボタンにマウスを当てて確認できます。外部で登録した自動起動は、この画面では変更・削除しません。

## 一覧の「自動起動」列

| 表示 | 意味 |
| --- | --- |
| 本体経由 | KotorinToysから自動起動する設定が有効 |
| OS（タスク）／OS（スタートアップ） | Windows側に自動起動の登録がある |
| なし | 対象の登録が見つからない |
| 無効 | 登録はあるが無効 |
| 要確認／確認できない | 希望と予約が合わない、または読取りに失敗した |

複数の方式が表示されたら、二重登録がないか確認してください。詳しい理由はセルにマウスを当てて確認できます。実行中アプリの起動元を示す列ではありません。

技術的な仕組み・判定範囲・保守手順は[開発者向け資料](development/startup-settings.md)に分けています。
