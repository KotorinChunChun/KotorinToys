# KotorinToys 0.1.10 開発版

Windows 11 x64向けの未署名prereleaseです。.NETランタイムを同梱します。

## 修正

- GitHub Releases一覧・配布台帳・SHA256SUMSを5分間キャッシュ。同時要求を集約し、再起動後も有効期限内は再利用します。
- 取得制限の原因と解除予定時刻を日本時間で表示。解除までは追加通信を抑止します。解除時刻がない場合も不明と明示します。
- 一覧詳細・導入できない理由・単体/一括導入・本体アップデート画面へ、取得制限の原因を残します。
- キャッシュから読む場合も製品・版・配布先・容量・SHA-256を検査し、期限切れ情報をインストール可能とは判定しません。

本体の「本体アップデート」で「開発版（prerelease）も更新対象にする」を選ぶと確認できます。手動導入は`KotorinToys-0.1.10-setup.exe`を使用してください。画像のスクリーンショットツールSSCaptureなど、子ツールの新しいバイナリは含みません。

同じ公開情報は取得から最大5分再利用します。新しいReleaseの反映がすぐでない場合は期限後に「状態を更新」してください。既に発生中のGitHub側の制限を解除する機能ではありません。

## 検証と境界

全自動回帰1,126件が成功しました。自己完結発行、setup非実行展開の602ファイルと一時補助197ファイルの容量/SHA-256、秘密情報/禁止ファイル、同梱ランタイム、共通アイコンを検査済みです。公開後に匿名再取得も照合します。詳しい結果は[実装・公開報告](v0.1.10-imp.md)へ記録します。

このPCへのインストール/自己更新、実GitHubの取得制限解除まで待つ受入、全収録ツールの全機能受入を完了した版ではありません。署名による発行元保証ではなく、固定配布元・製品・容量・ハッシュの照合による配布です。設定・履歴・自動起動予約は保持する既存仕様を維持します。
