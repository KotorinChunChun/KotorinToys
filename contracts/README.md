# 共通契約

本体と各ツールの間で共有する情報の説明を置きます。

現在の管理連携は `ManagementEndpoint.cs` で定義しています。各独立ツールは同じ実装のコピーを保持し、親フォルダーなしでもビルドできます。変更時は3コピーとの一致を確認します。

名前付きパイプは `KotorinToys.<WindowsユーザーSID>.<tool-id>`、現在のユーザー専用です。1行の `status`、`show`、`stop` を受け付け、JSONで `pid` と `ready` を返します。UIスレッドで画面表示と正常終了を実行し、ワーカープロセスは窓口を持ちません。本体は応答PIDの実行パスも照合します。

本体は終了要求を送信しただけでは停止完了にせず、プロセス終了を待って再検出します。タイムアウトや応答なしは確認できない状態として表示します。インストールと自動起動の契約は別途確定します。
