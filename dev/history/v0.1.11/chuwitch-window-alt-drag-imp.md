# ChuwitchWindowのAltドラッグと隣接追従

2026-11-08。ChuwitchWindowの動作設定にAlt＋左ドラッグ移動と隣接ウィンドウの追従を追加した。どちらも既定はオフ。追従の対象は、ドラッグ開始時と同じモニターにあって、ドラッグ中のウィンドウと辺が重なる方向で12物理ピクセル以内に近づいたウィンドウ。追従を始めたあとは左ボタンを離すまで相対位置を保持する。

子コミット`79703db`を採用する。既存のRDP移動変更は子の作業ツリーに残し、採用コミットから作った実行ファイルを検証に用いた。Windowsのフック登録と解除、旧設定の既定値、吸着距離、追従後の位置を含むRustの65件が成功した。フロントエンドは設定トグルを含む8件、型検査、ビルドが成功した。実マウスでの複数モニター操作は未確認。

新しい子コミットを隔離環境へ反映した状態でも、本体の通常の全回帰1,292件が成功した。生ログは`logs/regression-20261107/adopted-final-with-chuwitch.log`。

利用手順は子の[ユーザーガイド](../../../tools/ChuwitchWindow/docs/USERS_GUIDE.md)を参照。

- [x] `f5709a7`で中ボタンだけのドラッグ設定を追加した。追従はどちらの入力でも使える。すでに吸着したウィンドウの隣にも吸着し、操作対象を含む最大4枚が動く。
- [x] Rust 67件、フロントエンド8件、型検査、開発版ビルドが成功した。実マウスでの連続ドラッグは未確認。試験結果と修正版EXEは`logs/chuwitch-group-drag-20261108/`に保存した。

## 実機確認と8枚の前面化

- [x] 4枚版の実機試験では、修飾キーなしの中ボタンで約2.5秒ドラッグし、同じモニター上の4枚が同じ移動量で動いた。一方、最初のドラッグでは残りの窓が途中で合流し、開始時の並びがずれた。生ログは`logs/chuwitch-group-drag-20261108/physical/trace.csv`。
- [x] 子`7e9682d`で、ドラッグ開始時に最大8枚を選び、すべてに同じ移動量を適用するようにした。グループを起動中に保持し、メンバーのタイトルバーをクリックすると表示中の窓をまとめて前面に出す。
- [x] 8枚版はRust 67件、フロントエンド8件、型検査、ビルドが成功した。実機では利用者が中ボタンを約2.6秒押したまま移動し、75回の座標サンプルすべてで8枚の移動量とサイズが一致した。終了時は全窓が右へ68px、上へ113px移動した。タイトルバーを左クリックした後、約69msで計測窓より上にある対象が0枚から8枚になり、座標は変化しなかった。
- [x] 計測窓を閉じ、修正版を`--startup`で非表示起動した。PID 41304の管理窓口から準備完了を受け取った。生ログと再起動記録は`logs/chuwitch-eight-window-20261108/physical/`。
