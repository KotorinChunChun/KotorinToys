# KotorinToysの使い方

アプリのインストール、起動・停止、自動起動をまとめて操作できます。この説明は開発中の修正版が対象です。公開済みの旧版では表示・対応機能が異なります。

## 一覧の版・解説・状態

| 列 | 見る内容 |
| --- | --- |
| 導入Ver | インストール済みの版。未導入なら「未導入」 |
| 公開Ver | 確認できた公開版の番号。未確認なら「—」 |
| 更新 | あり／なし／未導入／未対応 |
| 現在の状態 | 実行中・停止中・確認中など |
| 自動起動 | 本体経由・OS側の登録・なしなど |
| 詳細 | 短い案内。マウスを当てると理由と対処を表示 |

公開日・開発版かどうかは「公開Ver」にマウスを当てて確認できます。「未対応」は、本体で更新できない配布形式か、公開情報などをまだ確認できない状態です。理由はセルにマウスを当ててください。未確認の版を「最新」とは判定しません。

一覧は起動時と「状態を更新」で取得します。通信できないときは最後の正常な一覧を残します。この仕組みを含む本体への初回更新後、共通仕様に対応したアプリの追加・版更新に本体の再更新は不要です。

## 選択したアプリを操作する

| ボタン | 操作 |
| --- | --- |
| 起動 / 設定を開く | 停止中なら起動。実行中なら画面を前に出す。行のダブルクリックでも同じ |
| 停止させる | 正常終了を依頼する。停止中は押せない |
| 使い方を開く | アプリの説明書を開く |
| GitHubを開く | アプリの公開ページを開く |
| インストール | 未導入のアプリを導入する |
| アップデート | より新しい公開版へ更新する |
| アンインストール | アプリを削除する。設定・履歴は保持する |

押せないボタンにマウスを当てると理由が分かります。実行ファイルなし、未対応、状態確認中・起動中・終了中などでは操作を制限します。録画・書出し中で終了を拒否されたら、作業を終えてから再操作してください。強制終了はしません。

## 本体全体のボタン

- 状態を更新：アプリの状態・一覧・公開版・自動起動を確認。
- 本体設定・自動起動：サインイン時に起動するアプリを設定。[この画面の操作説明](startup-settings.md)
- 一括インストール：チェックしたアプリをまとめて導入・更新。削除やFFmpegの操作もこの画面。
- 本体アップデート：新しい本体を取得して更新。設定・履歴を保持し、子アプリとPCは再起動しない。[詳しい手順](self-update.md)

本体を閉じても、各アプリは動作を続けます。

## 困ったとき

| 表示・状態 | 対処 |
| --- | --- |
| ZIP版を利用 | 本体からの導入は未対応。「GitHubを開く」からZIPを取得・展開 |
| 実行ファイルなし | 未導入ならインストール。導入済みなら導入先を確認し、必要なら修復 |
| 公開版を再確認／公開Verが「—」 | 通信状態を確認し、時間をおいて「状態を更新」 |
| GitHubの取得回数制限 | 時間をおいて再確認。連続で更新を押さない |
| 自動起動を設定できない | 正式インストールが必要。ZIP・開発EXEの配置だけでは設定できない |
| 操作できません／要確認 | セルにマウスを当て、理由に応じて対応。設定・履歴を削除しない |

ShortcutKeyCounterの「ZIP版を利用」は故障ではなく、配布形式の制約です。起動用EXEも見つからない場合は起動ボタンを無効にします。ZIP版の手順は[各アプリの使い方](../tools/ShortcutKeyCounter/docs/users-guide.md)を確認してください。

## SSCaptureのFFmpeg導入

1. SSCaptureを正式インストールします。
2. 「停止させる」でSSCaptureを終了します。
3. 「一括インストール」内の「FFmpegを導入 / 修復」を押します。
4. 完了後、SSCaptureを起動し直します。

SSCapture以外のFFmpeg設定は各アプリの説明書を確認してください。

## 高度な設定について

ローカル配布台帳は開発・検証用です。通常はGitHub Releasesを使ってください。技術的な仕様・判定条件・保守方法は[開発者向けガイド](DEVELOPERS_GUIDE.md)に分けています。
