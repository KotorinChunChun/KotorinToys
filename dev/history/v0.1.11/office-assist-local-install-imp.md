# OfficeAssistのローカル導入

2026-10-27。依頼：OfficeAssistをこのPCにインストールし、通常のKotorinToysから起動できるようにする。

## フェーズ

- [x] 1：通常の配信一覧に、このPCで明示した未公開製品を安全に合成する。テスト・ビルドを行いコミットする。
- [ ] 2：OfficeAssistのローカルインストーラーを作成し、導入先・本体・既存プロセスと設定を確認してから導入する。
- [ ] 3：本体を再起動し、導入検出と本体経由の起動・管理を確認する。既存設定・他のアプリの保持を確認し、結果を記録する。

## 方針

- `local-tools.json`は配信キャッシュと別に保持し、通常の製品識別と導入済み判定を通った未公開・非MSIXの製品だけ追加する。配信側・旧登録とIDまたはAppIdが重複するものは上書きしない。
- OfficeAssistの公開先を推測しない。ローカルsetupで現在ユーザーの登録を行う。Windowsのアプリ一覧から削除できるが、本体の公開配布連携・本体からのアンインストールは未対応。
- 既存の開発版OfficeAssistと本体は管理窓口で正常停止し、対象PID・パスと終了を確認する。Excelと他のアプリは停止しない。設定・履歴・既存自動起動予約は変更しない。
