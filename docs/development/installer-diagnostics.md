# インストーラー診断の実装

[開発者ガイド](../DEVELOPERS_GUIDE.md)へ戻る。利用者の操作は[ログの保存とエラー対処](../USERS_GUIDE.md#インストールでエラーが出たら)を参照してください。

EXE導入・削除の診断はInstallerDiagnosticsが実行ごとに保存します。Innoの終了コードはInstallerAdapterで分類し、MSIXの既存診断と区別します。Innoの/LOGは引数リストで渡し、空白・日本語を含むパスも一つの引数へ保持します。

SSCapture補助は導入先ハッシュ・root・operation・今回のutcを照合し、一致したmessageだけを取り込みます。ログなし・破損・読取不能では理由を推測せず、その状態を表示します。

- 診断先の作成に失敗した場合はsetupを開始しない。
- 実行後の結果保存だけが失敗してもsetupを再実行しない。
- 開始前の失敗には終了コードを付けない。
- 終了コード0だけで導入成功にせず、登録・製品識別・実EXEの版を照合する。
- ログを自動アップロードせず、設定・履歴・認証情報を収集しない。

結果は実行ごとのinstaller.log・operation.txt等へ残します。インストーラーの失敗と結果記録の失敗を区別し、詳細ログの画面保存と自動診断保存も区別します。

この機能の版別結果は[0.1.10の報告](../../dev/history/v0.1.10/v0.1.10-imp.md)にあります。報告の件数を現行説明の実測として転載しません。
