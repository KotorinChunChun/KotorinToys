# KotorinToys 利用ガイド

KotorinToysは、収録したWindows向け便利ツールの導入、起動、状態確認、自動起動予約、使い方へのアクセスをまとめて扱う管理アプリケーションです。

本書は開発中のソースに対応します。2026年10月15日の追加アプリ連携・操作行整理・更新時の公開照合は、公開済みインストーラーへまだ反映していません。

2026年10月16日追加：この機能を含む本体への初回更新後は、GitHubのmain/config/tools.jsonの変更だけで一覧を差し替えます。起動時と「状態を更新」で取得し、追加・非表示・順序・一言解説を反映します。通信できない場合は前回の正常な一覧を維持します。一覧から削除しても停止・アンインストール・自動起動解除は行いません。[運用手順と制約](online-tool-catalog.md)を確認してください。

## 一覧の版・解説・状態

一覧にツールの一言解説、導入済み版、公開版、更新の要否を表示します。導入済み版は正式登録された実行ファイルから取得し、開発フォルダーだけの配置は「未導入」と区別します。

同梱の初期一覧は8件で、取得したconfigによって変わります。追加のCapchunWindow（旧CapchunScreen）／ChulipVideo／ChunapToolとShortcutKeyCounterは本体用インストーラーが未公開のため、本体からの正式導入・更新はできません。HttpSelectorは後述の署名付きMSIXを利用します。CapchunWindowとChulipVideoのFFmpegは各アプリの設定で指定します（本体のFFmpeg導入はSSCapture専用です）。ひとこと解説はconfigのsummaryで変更できます。

起動時と「状態を更新」でGitHub Releasesと製品別配布台帳を照合します。独立した「公開版を確認」ボタンはありません。公開済み開発版も対象にし、開発版であることを併記します。通信失敗・API制限・台帳欠落では「公開版を確認できません」とし、同梱台帳の版を表示しても「最新です」とは判定しません。

「選択ツールを更新」は、その操作内で最新公開情報を取得し直します。正式導入済みで対応インストーラーがあるツールは、未照合・同じ版でも押して再確認できます。新しい版を確認できた場合だけ、その製品をチェックした導入画面へ進みます。導入済み版と取得対象版を確認して「選択をインストール / 更新」を実行してください。同じ版・通信失敗・未対応製品では導入しません。既存の導入先と保存データを保持し、正常停止の拒否時は中止します。実行中だった対象は更新後に起動状態へ復帰し、元が停止中なら起動しません。公開版より新しい導入済み版を古い版へ戻すことはありません。

画面下部の「全体」は全ツールの状態件数、「選択」は現在選んだ行、「最終操作」は直前に操作したツールの結果です。以前の下部表示は最終操作だけだったため、3ツールが実行中でもLiveTextMarkerだけが残ることがありました。

操作ボタンは「選択中アプリ」と「本体全体」の別行です。選択行には「起動設定を開く」「停止させる」「使い方」「GitHubを開く」「選択ツールを更新」、本体行には「状態を更新」「本体設定・自動起動」「導入・削除 / FFmpeg」「本体アップデート」を置きます。

「本体アップデート」は本体自身の現在版・公開版を確認し、新しい版をダウンロードして正常終了・保持付き更新・本体再起動を行います。正式版を既定とし、開発版は明示選択と同意が必要です。同版・旧版・未確認・開発実行では更新しません。取得・準備中は取消できます。子ツールの停止やOSの自動再起動は行いません。今回の開発ソースの機能であり、既存の公開済み／インストール済み本体には未反映です。[本体更新の詳細](self-update.md)を参照してください。

「GitHubを開く」は選択したアプリのリポジトリのトップページを既定ブラウザーへ渡します。configのrepositoryUrlで設定し、インストーラーの公開状態とは別に使用できます。同梱configでは既存4件とChunapToolの公開先を設定しています。公開先が未設定のアプリではボタンを無効にし、ツールチップに未設定と表示します。

一覧でツールを選び、「起動設定を開く」で停止中のツールを起動します。実行中の場合は既存画面を表示します。これは従来の起動・画面表示ボタンの名称変更です。「停止させる」で正常終了を要求し、「状態を更新」で状態と公開情報を再確認し、「使い方」で各ツールのREADMEを開きます。実行状態は4秒ごとにも更新します。

データ行のダブルクリックでも「起動設定を開く」を実行します。起動済みの画面は前面へ表示し、最小化されている場合は復元します。

起動処理中、実行中、停止処理中、停止中、確認できないを区別します。撮影・録画・書き出し等の処理中は、ツール側で操作を完了またはキャンセルしてから本体の「停止させる」を再実行してください。応答しないプロセスを本体から強制終了する機能はありません。

本体を閉じてもツールと通知領域アイコンは動作を続けます。「本体設定・自動起動」でサインイン時の起動方式を設定できます。

## 導入・削除の完了表示

「導入・削除」で対象をチェックし、インストール／更新またはアンインストールします。未署名の開発版であることを確認してから進めてください。設定・履歴は保持します。

処理が終了すると、上部に成功・失敗・要確認・再起動待ち・未実行の件数、表に各製品の結果と理由を表示します。「詳細ログを表示」で途中経過を確認できます。全件成功と一部失敗は区別し、完了後は「閉じる」で本体へ戻れます。再起動待ちの場合も自動再起動はしません。

## SSCaptureのFFmpeg導入

SSCaptureを正式導入し、本体の「停止させる」で停止した後、「導入・削除」の「FFmpegを導入 / 修復」を押します。固定9.0.2のFFmpeg／FFprobeを[FFmpeg公式が紹介する配布元](https://ffmpeg.org/download.html)の[Gyan GPLv3ビルド](https://www.gyan.dev/ffmpeg/builds/)から直接取得します（約110 MB）。再起動して録画を確認してください。

容量と固定SHA-256を照合し、実行ファイル横のtoolsへ録画用の2ファイルとライセンス・READMEを配置します。これは署名による発行元検証や実録画の確認ではありません。既存ファイルはバックアップ付きで置き換え、失敗時は元へ戻します。復旧未完了の場合はエラーに示したバックアップを削除しないでください。設定・履歴・WindowsのPATHは変更せず、公開済みインストーラーへの同梱もしません。

## HttpSelectorの導入

HttpSelectorは[署名付きMSIXの導入手順](../tools/HttpSelector/docs/INSTALL_MSIX.md)に従ってインストールしてください。HTTP/HTTPSの関連付け登録に必要なため、EXEのコピーだけで利用しません。MSIXの候補登録後、Windowsの「設定」→「アプリ」→「既定のアプリ」でHTTPとHTTPSにHttpSelectorを指定します。既定値を本体が強制変更することはありません。

本体は登録済みの署名付きMSIXを起動・表示・停止・状態確認します。未導入、旧版、登録確認不能のときはMSIX導入・更新の案内を表示し、開発EXEには切り替えません。Inno台帳によるインストール・更新とは別の導入経路です。自動起動には「KotorinToys経由」を選んでください。

危険性が疑われるURLやQuad9で確認できないURLは、割り込みオフやルール一致でも開く前に警告します。キャンセルが初期選択です。Quad9へ送るのはサブドメインを含むホスト名だけで、元URL・パス・クエリは送りません。詳しくは[HttpSelector利用ガイド](../tools/HttpSelector/docs/USERS_GUIDE.md)を参照してください。
