# KotorinToys 0.1.15 開発版

Windows 11 x64向けの未署名開発版です。実行に必要な.NETランタイムを同梱しています。

- 本体の更新画面を開くと、現在の版が通常版か開発版かを調べ、同じ種類の最新版を自動で確認します。
- 更新がある場合は「アップデート」だけで準備を開始できます。種類を切り替える場合はチェックと確認が必要です。切り替え先が古いときは注意を表示し、設定・履歴を退避します。
- SSCapture 0.1.7の公開情報を同梱しました。旧登録0.1.0と実行ファイル0.1.1が混在する既知の状態からの更新に対応しています。

v0.1.14以前からの自己更新では、現在お使いの画面で「開発版も更新対象」を選び、同意して更新してください。設定・履歴は保持します。

配布物はSHA-256で照合しますが、電子署名による発行元の保証はありません。詳しい使い方は[本体のアップデート](https://github.com/KotorinChunChun/KotorinToys/blob/v0.1.15/docs/self-update.md)をご覧ください。
