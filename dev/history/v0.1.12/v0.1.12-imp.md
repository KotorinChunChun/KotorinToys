# KotorinToys 0.1.12 実装計画・報告

対応：[要求](v0.1.12-req.md)。2026-10-24。公開main cfc7226を基点とするfeature/v0.1.12。元作業ツリーの差分と未公開TimecardOCRを含めない。

## 0. 事前確認

SSCaptureの別配置は、管理応答のPIDを実プロセスのセッション・EXEパスと照合して検出している。従来は理由文だけにパスを埋めていた。安全照合を緩めず、構造化した確認対象／実行中パスを本体内の状態へ追加し、エラーメッセージからのパス抽出を避ける。

DevLauncherの検索と複数カテゴリのバッジを参照するが、アプリ登録・起動管理・自動起動予約は移管しない。KotorinToysの既存の4表示、選択ID、並べ替え、config更新、グレーアウトを維持する。

## 1. 順序と方針

- [x] P1 / R1：構造化パス、別配置セルのボタン、詳細の正式導入先ボタン。現在ユーザーの同セッションPID・パスをクリック直前にも照合する。ローカルEXEのみをExplorerで選択表示し、対象アプリは実行しない。停止・移動・設定書換なし。消失・照合不能・処理中は開かず理由を示す。限定テスト・ビルド後コミット。
- [x] P2 / R2：検索欄、カテゴリタグとリセット。空白区切りAND検索・大文字小文字を無視、カテゴリは単一選択（1ツールが複数タグに所属）。カテゴリ候補はconfigから動的に作り、未分類も表示。絞り込みの積、0件時の無効化、config変更後の選択・条件保持、旧表示設定の互換をテストしてコミット。
- [ ] P3：利用者／開発者資料を更新し、全回帰・最小幅の描画・最終UI確認を行い結果をコミット。公開・正式本体の終了／導入・子ツール変更はしない。実機操作ができない場合はその境界を明記する。

## 2. 影響範囲

ToolState／ToolManager.Status、Dashboardの詳細セルと詳細ダイアログ、Explorerへの限定した起動部、Dashboard.View／ViewStore／Refresh、専用テスト・使い方。新しい独自画面は増やさず、既存の共通タイトル・04アイコンを保つ。版は0.1.12とし、バイナリ配布は別指示まで行わない。

検索条件は表示専用保存へ追加し、起動設定・所有トークン・履歴は変更しない。旧ファイルに追加項目がなくても既定の空検索・全カテゴリで読み込む。検索・カテゴリ変更はローカルの表示だけを変え、通信を開始しない。
