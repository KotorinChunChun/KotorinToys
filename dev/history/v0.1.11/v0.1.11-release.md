# KotorinToys 0.1.11 開発版

Windows 11 x64向けの未署名prereleaseです。.NETランタイムを同梱します。

## 主な変更

- 表示を「通常・要更新・未導入・すべて」で切り替え。未導入行の状態などを「-」に整理しました。
- 公開Ver列を廃止し、更新がある場合だけ「要(対象版)」を表示。公開日などは詳細説明で確認できます。
- カテゴリの複数タグ、自動起動の「Toys経由」表記、設定項目と操作ボタンの説明を追加しました。
- 状態不明の原因を具体化し、別配置のEXEが応答した場合は対象と実行中のパスを表示します。「ZIP配布あり」は公開情報であり、利用中の検出とは区別します。
- インストーラーの失敗理由・終了コード・実行段階を表示し、詳細ログの自動保存・テキスト保存に対応しました。

設定・履歴・自動起動予約を保持します。本体アップデートでは子ツールやPCを再起動しません。開発版は本体アップデート画面で「開発版（prerelease）も更新対象にする」を選択してください。手動導入は`KotorinToys-0.1.11-setup.exe`を使用します。
