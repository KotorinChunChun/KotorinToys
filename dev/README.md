## 配置規則

- 継続的なルールと目録は `dev/` 直下
- 版別資料は `dev/history/vX.Y.Z/`
- 版に属さない調査は `dev/research/<対象>/`
- テスト動画・生ログ・実行時生成物は対象版の `logs/<実行識別子>/`
