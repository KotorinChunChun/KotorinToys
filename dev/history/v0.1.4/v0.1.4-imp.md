# KotorinToys 0.1.4 実装計画・報告

対応要求: [要求](v0.1.4-req.md) / 作成日: 2026-10-19
ブランチ: `feature/full-refactoring` / 状態: P1/P2完了、EveryDB公開0.1.5との統合・一覧接続は[0.1.6](../v0.1.6/v0.1.6-imp.md)で完了する。

## 0. 事前確認

- 既存のMsixInstallationは現在ユーザー登録の検出・Manifest照合・Package Familyによる起動に対応済み。
- PublicReleaseClient、PackageCatalogReader、InstallerAdapterは3成分の版・Inno EXE専用。ToolInstallationRunnerはMSIXを明示的に拒否していた。
- HttpSelectorの固定Identityは `HttpSelector.Development`、Familyは `HttpSelector.Development_xtxrnffqrdk4w`、Publisherは `CN=KotorinChunChun`、Applicationは `App`、x64。
- 参照チャットで0.0.3.3の署名付きMSIX公開を確認。AppInstallerのGitHub配信MIME問題とは分離し、ローカル取得したMSIXをWindowsのPackageManagerで処理する。
- `Remove-AppxPackage -PreserveApplicationData`は通常の署名付きMSIXの保持策にはならないため、削除前にLocalState/RoamingStateを本体のユーザー領域へ退避する。更新も同じFamilyを維持する。

## 1. 実装順序・コミット単位

- [x] P1 / R1: MSIX種別・4成分版・固定配布先・SHA256SUMS照合、公開取得の回帰テスト。
- [x] P2 / R2: Windows署名検証・Manifest検証、現在ユーザー限定のPackageManager連携、データ退避復元、正常停止・予約整理、失敗系テスト。
- [x] P3 / R3: メイン一覧・詳細設定との連携、GitHub URL登録、利用方法更新、全体回帰・実公開物の読取照合。0.1.6へ統合して実装・検証した（同版報告を参照）。

## 2. 実装方針・影響範囲

- 既存Inno形式を既定のまま維持し、明示的なMSIX種別のみ追加する。未対応のFamily・署名者・パッケージ形式は拒否する。
- 取得前は公開版・固定URL・サイズ・ハッシュ、停止前と展開直前はファイルのSHA-256・署名者・Manifestを照合する。
- 配布物検証とOS展開、データ保持を分離し、OS操作は注入可能にする。テストは既存の実インストールを変更しない。
- PackageManagerのNoneオプションを使用し、強制終了・強制更新・ダウングレードを行わない。
- MSIXの失敗理由にHRESULTと対処を記録する。信頼されない証明書を勝手に登録しない。
- Windows SDK型のため本体・テスト・MaintenanceのTFMへWindows API版を明示する。Windows 11 x64の既存対応範囲は変えない。

## 4. 実装で判明した追加対応

- 再開時の作業ツリーは旧本体0.1.3だが、EveryDB側は別worktreeの`feature/everydb-common-installer`で本体0.1.5まで公開済みだった。全体試験で子EveryDB 0.1.1と旧本体の固定公開台帳の不一致を検出した。MSIX単体は成功しており、P3は既存EveryDB対応4コミットを作業ブランチへ統合した0.1.6として継続する。公開版を差し替えたり主ブランチへマージしたりしない。
- Windows SDK参照を明示してPackageManagerを直接使用。署名検証もWinVerifyTrustで行い、PowerShellの追加インストールを製品の実行条件にはしない。
