# よくある質問

## 収録ツールはどこにありますか？

現在の初期環境には収録ツールを配置していません。対象ツールの実物確認後、独立Gitリポジトリとして `tools/<tool-id>/` に配置するか、既存の場所を `catalog/` から参照します。

## 連携用の実行ファイル名やインストールコマンドは決まっていますか？

まだ決まっていません。定義書では既存ツール確認後まで保留されています。推測した値は登録しません。

## この段階で製品を起動できますか？

まだ製品本体のソースと実行環境を作成していないため、起動できません。現在は開発資料とリポジトリ構成の準備段階です。
