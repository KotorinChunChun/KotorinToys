# 操作可否と理由の実装（開発者向け）

利用者向けは[利用ガイド](../USERS_GUIDE.md)・[自動起動の操作](../startup-settings.md)。実装はToolActionPolicyとActionAvailability、画面側のActionHintsを正本とする。

| 操作 | 有効条件 |
| --- | --- |
| 起動・画面表示 | 状態が停止中／実行中、対応能力あり、実行ファイルあり。MSIXは正式導入・対応版が必要 |
| 停止 | 実行中、正常停止能力・実行ファイルあり。停止中／状態不明／遷移中は不可 |
| 使い方 | 正規化した文書パスにファイルがある |
| インストール | 未導入・停止中・対応する公開台帳を照合済み |
| 更新 | 導入状態を確認済み・実行ファイルあり・より新しい公開版あり・対応する公開台帳を照合済み |
| 修復 | 正式Inno登録と製品情報が一致するEXE欠落・停止中・同じ版以上の確認済み公開物あり。導入先を変更しない |
| 削除 | 正式導入と削除EXEあり。MSIXは専用登録照合。遷移中・状態不明は不可 |
| FFmpeg | SSCaptureの正式導入・EXE存在・停止中 |
| 自動起動 | 正式導入・EXE存在・silent-start。本体経由は本体の正式起動先も必要 |

画面処理中は競合する操作を無効にする。公開確認中は導入・更新を無効にする。バッチは対象0件・不適合なチェック対象を含む場合に無効化する。グレーアウトは認可の代用ではなく、処理開始直前にも同じ条件を再照合する。終了拒否の撮影・書出しを強制停止しない。

無効理由はButton.AccessibleDescriptionとツールチップに設定する。標準ToolTipが出ない無効コントロールは親のMouseMoveから案内する。既定のファイル存在・状態検出は実体を読み、テストだけ明示的な注入依存で置換する。

詳細セルのクリック／Enterは読取専用画面を開く。並べ替え後の操作対象は行番号ではなくツールIDで照合する。[修復・表示保存・公開前検査の詳細](operation-improvements.md)を参照。

`--ui-policy-tests`は共通判定・メイン・詳細導入のフォームを、`--startup-form-tests`は自動起動設定を検証する。利用者の設定・予約・常駐は変更しない。ビルド・フォーム測定・実サインイン・物理音声の受入は別の証跡である。
