# KotorinToys 0.1.17 開発版

既知の問題：引数なし起動ではルートパス末尾の区切りにより、Toys経由のアプリ起動を見送る場合があります。修正は準備済みです。暫定的には正式導入先のKotorinToys.exeへ `--root C:\path\to\KotorinToys` を指定して起動します。指定先は実際の正式導入フォルダーに置き換えてください。GUIの更新確認自体は動作します。

- 管理画面を開いたときに本体の公開版を確認し、新しい同種の版があれば更新ダイアログから自動更新を開始します。開発版は開発版、通常版は通常版が既定です。
- 手動起動・サインイン起動のどちらでもToys経由対象を確認し、未起動のアプリを起動します。起動済みのアプリは再利用します。
- 手動更新との競合と重複案内を防止し、更新の確認結果を本体の設定フォルダーのupdates/gui-check.jsonへ保存します。

設定・履歴・自動起動予約は保持します。取得・準備中は更新を取り消せます。通常版と開発版の切替は確認が必要です。Windows 11 x64向けの未署名開発版で、必要な.NETランタイムを同梱しています。
