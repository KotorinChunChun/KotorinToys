# 署名付きMSIXの管理

HttpSelectorはMSIX形式で配布します。KotorinToysの一覧から導入・更新・削除し、署名やアプリの識別を確認します。

## 操作

1. 「状態を更新」でGitHubのツール一覧と公開版を取得します。
2. HttpSelectorを選びます。未導入なら「インストール」を押せます。導入済みの場合、「アップデート」を押せるのは新しい公開版があるときだけです。本体は4成分のバージョン番号と日本時間の公開日を表示します。
3. 対象とバージョンを確認して実行します。アプリが通常終了を拒否した場合や署名の検証に失敗した場合は、処理を中止して結果欄に理由を表示します。
4. 削除するには「アンインストール」を押します。対象は、現在のユーザーに登録された固定Familyだけです。Innoのunins000.exeは不要です。

まとめて操作する場合は「一括インストール」を開きます。

初回に署名の信頼を確認するよう求められたら、[HttpSelectorの導入説明](https://github.com/KotorinChunChun/HttpSelector/blob/main/docs/INSTALL_MSIX.md)を読み、配布元と証明書を確認してください。本体は証明書を自動登録しません。

HTTP／HTTPSの関連付け候補が登録された後、既定アプリの選択はWindowsの設定で行います。インストールしただけで既定のブラウザーを変更する操作とは別です。

- 更新は同じPackage Familyを維持します。更新前にLocalState/RoamingStateを退避し、展開後・再起動前に保持を照合します。
- 削除前に同領域を本体のユーザーデータ領域へ退避します。DB本体だけでなく署名・バックアップ・DPAPI整合性キーも含めます。退避できなければ削除しません。
- 保存先は `%LOCALAPPDATA%\KotorinToys\msix-data\HttpSelector.Development_xtxrnffqrdk4w\` です。現在ユーザーとSYSTEMだけのアクセス許可を設定します。
- 次に本体からインストールするとき、同じユーザーとFamilyにデータを復元してからアプリを起動します。異なるデータが既にある場合は上書きせず、「要確認」と表示して処理を止めます。退避したデータは自動で削除しません。
- OSの設定から直接アンインストールした場合や本体の保持領域まで手動削除した場合は、本体で事前退避できません。削除・再導入は本体から行ってください。
- 自動退避の上限は10,000ファイル・4GBです。リンク、保持記録の不一致、退避中の変更は中止理由になります。超える場合は手動バックアップの管理が必要です。

KotorinToys経由の更新・削除ではアプリのデータを退避し、同じユーザーで再導入するときに復元します。退避・照合できない場合や、既存データと競合する場合は「要確認」で止まります。

Windowsの設定から直接削除した場合や、保持領域まで手動で削除した場合は本体で事前退避できません。データを保持する操作は本体から行ってください。「リセット」は設定を消す可能性があるため選ばないでください。

導入前にWindowsの署名検証、Publisher `CN=KotorinChunChun`、証明書指紋、Manifest、payload全ブロックを検証します。HttpSelectorのFamilyは `HttpSelector.Development_xtxrnffqrdk4w` だけです。別のFamily・発行元・証明書への移行はconfigの変更だけでは許可しません。

| 表示の例 | 確認すること |
| --- | --- |
| 証明書の信頼（0x800B0109） | 配布元の導入説明と証明書 |
| アプリ使用中（0x80073D02） | アプリ側の作業を終えて正常終了 |
| 依存・競合（0x80073CF3） | 画面の詳細とWindows側の登録状況 |
| アクセス権・ポリシー（0x80070005） | 画面の詳細、導入先やPCの利用制限 |

原因を確認できない場合は、エラー表示を控えて問い合わせてください。強制終了・自動削除・PCの自動再起動で解決する処理は行いません。

## 検証境界

署名付き実公開物の取得・署名・全内容・OS登録の読み取りと、OS操作を置換した自動テストで検証しています。実OSへのインストール・更新・削除／再導入、別PCの未信頼証明書環境は未受入です。[0.1.6の報告](../dev/history/v0.1.6/v0.1.6-imp.md)を参照してください。

## MdVisualizer

MdVisualizer 0.0.19.3以降は固定Family com.mdvisualizer.viewer_xtxrnffqrdk4wに対応します。証明書とPublisherは既存の共通固定値を維持し、別Family・別EXE・別配布元を拒否します。管理応答・MSIX・タグは4成分で一致させます。手動起動だけを許可し、--startupを付けません。設定は製品Familyごとに分離し、LocalState／RoamingStateに加えMdVisualizerの仮想Roaming設定も退避対象とします。操作手順は[MdVisualizer](mdvisualizer.md)を参照してください。
