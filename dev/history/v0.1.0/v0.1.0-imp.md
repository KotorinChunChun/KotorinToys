# v0.1.0 準備計画・実装報告

## 目的

添付された「KotorinToys プロジェクト定義とツール共通規約 v0.1.0」を正本として、製品実装に先立つ親リポジトリの開発環境を準備する。

## 今回の実施範囲

- 親Gitリポジトリの初期化
- 定義書に対応した標準フォルダーの作成
- 利用者向け・開発者向けの初期ドキュメント作成
- カタログ、共通契約、独立ツール配置先の入口作成
- v0.1.0の要求・進捗資料の配置
- ルートのGit除外規則の設定

## 保留した範囲

- 本体の技術言語、UIフレームワーク、プロセス分割、通信方式
- 既存ツールの配置・移動・一括改名
- ツールごとの実行ファイル名、引数、インストーラーURL、MSI製品コード、設定パス
- ツール登録、インストール・アンインストール処理、起動・停止・状態取得
- Windowsタスクスケジューラーへの実登録
- ビルド、製品起動、GUI受入、配布、公開

これらは既存ツールの実物確認または別途の実装指示が必要であり、定義書の保留事項を推測で埋めない。

## 検証

- Markdown内のローカルリンクを確認する。
- `git diff --check` で空白エラーを確認する。
- 文書のみの変更のため、製品ビルドやGUIテストは実施しない。
