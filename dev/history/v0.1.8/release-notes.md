# KotorinToys 0.1.8（開発版）

Windows 11 x64向けの未署名prereleaseです。.NET 10.0.13を同梱しているため、.NETの追加インストールは不要です。

## 主な変更

- 詳細セルをクリック、または選択してEnterで、原因と対処を開けます。
- 配布形式の未対応と、通信失敗・取得回数制限・公開情報の不一致を区別します。
- 正式登録を照合できるEXE欠落では、設定・履歴を保持した「修復」を使えます。同じ版以上の確認済み配布物と停止中の確認が必要です。
- 「導入済み」「更新あり」の絞り込み、並べ替え、列幅・列順・通常時サイズの保存に対応しました。
- 一括操作をインストール・更新／アンインストール／FFmpeg／開発者向けの4タブへ分けました。切替時は対象チェックを解除します。
- 公開前に一覧configと配布物の整合・秘密情報・同梱ランタイムを検査します。
- 公開0.1.5からは、署名付きMSIXの管理、VoiceMixerMicRouter／SpkRouterの登録、短い一覧表示、状態別のグレーアウトと無効理由の案内も追加されています。

## ダウンロードと更新

`KotorinToys-0.1.8-setup.exe`を使用してください。自己更新対応の本体では「本体アップデート」で「開発版も更新対象にする」を選ぶと取得できます。設定・履歴・自動起動予約を保持し、本体だけを正常終了・更新・再起動します。子ツールやPCは再起動しません。

SHA256SUMSは改変検知用です。電子署名による独立した発行元保証ではありません。

## 確認範囲と注意

採用ソースのRelease回帰1,031件、配布593ファイルの完全照合、秘密情報検査、04アイコンの確認を実施しました。このリリース作業では実インストール・修復・再起動は行っていません。物理音声・全録画機能の受入を保証するものではありません。

子ツールの新バイナリは今回再公開していません。FFmpeg・OCR外部ファイル・音声モデル等は各ツールの案内を確認してください。
