# 本体のアップデート

0.1.17以降は、管理画面を開くと本体が同じ種類の最新版を探します。開発版を使っている場合は開発版を、通常版を使っている場合は通常版を探します。新しいバージョンが見つかると、更新ダイアログが開き、ダウンロードと更新が始まります。

## 同じ種類の最新版に更新する

1. メイン画面の「本体アップデート」を開きます。
2. 本体が現在の版の種類を判定し、同じ種類の最新版を探します。
3. 新しい版が見つかったら「アップデート」を押します。

本体だけが終了・更新・再起動します。設定・履歴と自動起動設定は保持します。再起動時はToys経由のアプリを確認し、未起動なら起動します。配布物はGitHub Releasesから取得し、容量とSHA-256を確認します。電子署名はありません。

更新できない場合は、画面に表示された理由を確認してください。正式にインストールした本体以外からは自己更新できません。通信に失敗した場合は画面を開き直してください。

## 通常版と開発版を切り替える

1. 「通常版に切り替える」または「開発版に切り替える」を押します。現在使っている種類のボタンは押せません。
2. 本体が切り替え先の公開版を探します。確認画面でバージョンを確かめてから切り替えます。
3. 本体は設定・履歴を退避してから更新し、再起動します。

切り替え先が現在より古い場合は注意を表示します。古い版では、新しい版の設定を読み取れない場合があります。切り替え先の公開版がない場合は選べません。現在の版の種類を判定できない場合も、切り替え先の選択と確認が必要です。

失敗したときは画面の理由を確認してください。保存された結果は「ログを開く」で確認できます。設定・履歴の自動復元やOSの自動再起動は行いません。

v0.1.14以前は画面の操作方法が異なります。v0.1.0以前では自己更新に対応していないため、[GitHub Releases](https://github.com/KotorinChunChun/KotorinToys/releases)からインストーラーを取得して更新してください。

開発者向けの配布条件・実装・検証手順は[自己更新の開発資料](development/self-update.md)を参照してください。
